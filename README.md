# 星光 TV

星光 TV 是一个面向 Android 手机、平板和电视设备的视频播放客户端，支持点播、直播、搜索、收藏、播放记录及多种播放设置。

当前版本：`5.7.3`

## 主要功能

- 支持手机端和 Android TV 端界面
- 支持点播、直播、搜索与换源
- 支持播放记录、收藏和多线路配置
- 支持字幕、音轨、画面比例及播放器设置
- 支持本地配置、网络配置和自定义数据源
