配置中心改成状态面板

设置页当前是单列列表，信息密度足够但状态弱。草图把高频配置源、播放器、隐身模式、缓存、备份恢复放进统一状态面板，减少进入二级弹窗前的判断成本。

点播源显示源名、可搜索、可换源状态。
直播源显示频道数、EPG 同步、回看状态。
播放内核EXO / IJK / MPV 与当前缓冲策略。
数据维护备份、恢复、缓存清理合并在同区。

落地映射

  • 颜色：将 mobile 当前暖色纸面风格替换为 OLED 深色背景、冷光描边、珊瑚红播放强调和琥珀色配置状态。
  • 首页：保留 `activity_home` 底部导航和 `fragment_vod` 顶部功能区，把继续观看做成最高优先级状态卡。
  • 播放页：保留现有小窗播放器、剧集横滑和简介分区，增强播放 HUD、进度、网速与当前集选中态。
  • 直播页：保留三列列表，但改为右侧半透明抽屉，减少遮挡主画面，当前节目和回看信息放左下角。
  • TV 端：保留 leanback 横向网格，新增更明确的焦点边框和信息摘要，保证遥控器操作时不会迷失焦点。
