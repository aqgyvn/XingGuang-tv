# XingGuang iOS

This directory contains the iPhone and iPad client for XingGuang.

## Baseline

- Minimum deployment target: iOS/iPadOS 15.0
- UI framework: SwiftUI
- Project generation: XcodeGen
- Build verification: GitHub Actions on macOS
- Distribution target: TrollStore IPA

The Android application remains in the repository root Gradle modules. Android source files and resources are not modified by the iOS project.

See `docs/ios-development.md` for build and verification instructions.
